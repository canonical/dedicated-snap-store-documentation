Dedicated Snap Store
====================

Canonical's Dedicated Snap Store is a private, secure, and fully managed snap store for your organization. It allows you to distribute snaps to your users without exposing them to the public Snap Store. 

Product page: https://ubuntu.com/internet-of-things/appstore
Documentation: https://ubuntu.com/internet-of-things/appstore/docs/

This repository contains documentation for Dedicated Snap Stores. It allows the documentation to be templated with customer specific account details.

This set of documentation is based on the `Canonical Sphinx Docs Starter Pack <https://github.com/canonical/sphinx-docs-starter-pack>`_. See that project for general instructions.

See ``WORKFLOW.rst`` for instructions on adding or updating a domain for a specific Dedicated Snap Store.


Documentation
-------------

The Canonical Dedicated Snap Store documentation provides information about how to set up and manage your Dedicated Snap Store, including onboarding new customers, configuring store settings, and more.

Community and support
---------------------

Do you have questions about the Canonical Dedicated Snap Store? `Contact us <https://ubuntu.com/internet-of-things/appstore>`_ for more information about the Dedicated Snap Store!

You can report any bugs or issues you find through the `support portal <https://support-portal.canonical.com/>`_. Any documentation issues should be reported here in the GitHub repository.

Canonical's Dedicated Snap Store is covered by the Ubuntu Code of Conduct.
